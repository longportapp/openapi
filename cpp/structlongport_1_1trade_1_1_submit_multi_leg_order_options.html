◆ client_request_id

std::optional<std::string> longport::trade::SubmitMultiLegOrderOptions::client_request_id

Idempotent request ID for preventing duplicate orders. If not specified, idempotency control is skipped. The server caches this ID for 10 minutes.

◆ delayed_until

std::optional<int64_t> longport::trade::SubmitMultiLegOrderOptions::delayed_until

Time-condition submit time (Unix timestamp in seconds), later than now and no more than 90 days ahead. Only LO / MO support time conditions.
